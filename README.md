**"어디 가서 무엇을 볼 것인가"가 아니라, "왜 이 지역에 머물러야 하는가"에 답하는 체류형 여행 추천 서비스**

경상북도 15개 인구감소지역을 대상으로, 스쳐 지나가는 관광이 아닌 **머무는 여행**을 설계하고
그 여행이 지역에 남긴 기여를 공공 기준으로 환산해 보여줍니다.

## 서비스 개발 배경

경상북도 15개 시·군은 행정안전부가 지정한 **인구감소지역**입니다.
이 지역들에 사람이 오지 않는 것은 아닙니다. 다만 대부분 당일치기로 한두 곳을 둘러보고 떠납니다.
**방문은 있으나 체류가 없고, 체류가 없으면 지역에 남는 것도 없습니다.**

정부는 이 간극을 메우기 위해 「인구감소지역 지원 특별법」에서 주민등록인구 대신 **생활인구**를 지역 활력의 지표로 삼았습니다.
그 중 체류인구는 *"주민등록지가 아닌 지역을 월 1회 이상 방문해 하루 3시간 이상 머무는 사람"* 으로 정의됩니다.
지역에 필요한 것은 더 많은 방문객이 아니라, **더 오래 머무는 방문객**이라는 뜻입니다.

그러나 기존 여행 서비스는 여전히 "어디 가서 무엇을 볼 것인가"에 맞춰져 있습니다.
유명 관광지 순으로 나열하고, 체류는 사용자가 알아서 정하게 둡니다.

머물;경은 질문을 바꿨습니다.
**왜 이 지역에 머물러야 하는지**를 지역의 이야기로 설명하고,
머무는 것을 전제로 일정을 설계하며,
여행이 끝나면 **내가 이 지역의 생활인구에 며칠을 더했는지**를 돌려줍니다.

## 핵심 기능

### 1. 지역 추천

취향 9종(한옥·유교, 자연, 바다, 걷기, 힐링, 음식, 자전거, 역사, 밤하늘), 동행 유형 4종(혼자·커플·친구·가족),
희망 숙박일수를 가중 합산해 경북 15개 인구감소지역 중 **3곳을 추천**합니다.
추천 결과에는 매칭된 취향 태그, 추천 이유, 대표 장소가 함께 제공됩니다.

<!-- [사진 ②] 취향·동행·기간 선택 화면 → 추천 결과 3개 카드 화면 (2장 나란히) -->

### 2. 체류형 일정 자동 생성

1박당 **관광지·체험 3곳 + 음식점 2곳**을 순서대로 배치하고, 도착·출발 일정을 포함해
여행 전체 흐름을 구성합니다. 여행 기간 중 열리는 **지역 축제·행사는 자동으로 일정에 편입**됩니다.
마음에 들지 않는 항목은 개별 교체하거나, 일정 전체를 다시 생성할 수 있습니다.

<!-- [사진 ③] 날짜별 일정 화면 — 축제가 편입된 날이 보이면 가장 좋다 -->

### 3. 현장에서 필요한 정보

| | |
|---|---|
| **운영시간·휴무일** | 방문 요일과 대조해 **휴무 가능성을 경고**합니다. 단정하지 않고 원문과 함께 안내합니다. |
| **날씨** | 여행일까지 3일 이내는 단기예보, 4~10일은 중기예보로 **자동 전환**해 제공합니다. |
| **이동 경로** | 자차는 소요시간·거리·예상 택시요금, 대중교통은 소요시간·요금·환승·경로선을 구간별로 제공하고 지도와 길찾기로 연결합니다. |
| **지역 버스** | 15개 시·군의 **공식 버스 시간표 링크**와 관내 무료버스 안내를 제공합니다. |

### 4. 지역 스토리와 관광 정보

각 지역의 정체성을 담은 소개와 함께, 한국관광공사 데이터 기반 **지역 대표 사진**을 제공합니다.

<!-- [사진 ⑤] 지역 상세 화면 (스토리 + 대표 사진 영역) -->

### 5. 기여도 산출과 기록

여행을 완료하면 체류시간과 인원으로 **생활인구 산입일수**와 **예상 소비액**을 산출합니다.
방문한 지역은 스탬프로 모이고, 서비스 전체의 **누적 기여 현황**(총 체류일수·소비액·지역 랭킹)은
로그인 없이도 확인할 수 있습니다.

## 타 서비스와의 차별점

| | 기존 여행 플랫폼 | 머물;경 |
|---|---|---|
| **답하는 질문** | 어디 가서 무엇을 볼 것인가 | **왜 이 지역에 머물러야 하는가** |
| **추천 대상** | 인기·검색량 순의 유명 관광지 | **행정안전부 지정 경북 15개 인구감소지역으로 한정** |
| **일정의 단위** | 가볼 만한 장소 목록 | **1박 단위 체류 설계** — 관광지·체험 3곳 + 음식점 2곳, 기간 내 축제 자동 편입 |
| **정보의 신뢰** | 최신성과 출처가 불분명 | **출처·조회 시각 표기, 모르면 빈칸, 휴무는 단정 대신 경고** |
| **여행이 끝난 뒤** | 후기와 평점 | **생활인구 산입일수·예상 소비액을 공공 기준으로 산출** |

### 정확성을 문구가 아니라 구조로

여행 정보는 틀리면 사용자가 현장에서 손해를 봅니다.
"정확한 정보를 제공합니다"라고 쓰는 대신, 틀릴 수 없는 구조를 만들었습니다.

- **출처와 조회 시각을 함께 내려보냅니다.** 운영시간·경로 응답에는 데이터 출처와 조회 시각이 포함됩니다.
- **모르면 모른다고 합니다.** 외부 조회에 실패하거나 데이터가 없으면 임의로 채우지 않고,
  상태값과 안내 문구로 빈칸임을 명시합니다.
- **단정하지 않습니다.** 휴무일은 "휴무"가 아니라 "휴무일 수 있음"으로 안내하고 원문을 함께 보여줍니다.
- **교차 확인할 수 있게 합니다.** 무료버스 안내는 정책 근거와 예외 문구(시·군을 넘는 노선은 유료일 수 있음)를
  실측 요금과 나란히 보여줍니다.

### 지역에 남는 것을 숫자로 돌려줍니다

대부분의 여행 서비스에서 여행의 끝은 후기입니다.
머물;경에서 여행의 끝은 **이 지역의 생활인구에 며칠을 더했는가**입니다.
그 숫자는 서비스가 임의로 만든 점수가 아니라, 아래의 공개된 공공 기준을 그대로 적용해 산출됩니다.
